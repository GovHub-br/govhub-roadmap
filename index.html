Como usar

  • Sidebar à esquerda troca de seção — cada seção mistura tutorial, guia, referência e explicação, como uma página de suporte da Apple: organizado por assunto, não por tipo de conteúdo.
  • O selo colorido no título indica o tipo (verde=tutorial, azul=guia, roxo=referência, marrom=explicação). Clique num selo da barra de tipos no topo pra filtrar só aquele tipo dentro da seção atual.
  • Selos tracejados (lacuna / gap / dup / rascunho) indicam o que falta revisar, criar ou fundir.
  • "Dashboards & Relatórios" é conteúdo novo, ainda não existe no site — é a primeira versão da trilha de treinamento pra criar, manter dashboards e gerar relatórios no Superset. Precisa validação de quem já mantém isso hoje.
  • Clique no quadrado à esquerda de cada item pra marcar como concluído — salvo no navegador.

1. Clonar o repositório
git clone data-application-gov-hub
cd data-application-gov-hub
Configurar assinatura de commits →
2. Preparar o ambiente
make setup
cria .env a partir de local.env
instala deps (Poetry)
configura hooks do Git
build + up (Docker Compose)
configura conexão local do Airflow
valida config básica
3. Verificar os serviços
Airflow :8080
Superset :8088
Jupyter :8888
PostgreSQL :5432
Comandos do dia a dia
docker compose up -d
docker compose logs -f
docker compose down
make dev
make dev-check
make format
make lint
make test

Como usar

  • Linhas cinza (arestas) ligam cada nó ao seu pai na trilha — mesmo princípio visual do roadmap.sh: nó principal (roxo) no centro, sub-nós conectados por baixo.
  • Clique em qualquer nó pra marcar como concluído — fica salvo no navegador, sobrevive a reload.
  • Nós verdes ("→") são links de saída — apontam pra outra seção da documentação.
  • Redimensione a janela: as arestas recalculam a posição automaticamente.

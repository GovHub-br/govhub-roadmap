Como usar

  • A espinha percorre as 7 seções na ordem em que fazem sentido para quem chega: instalar, entender, operar, visualizar, sustentar, governar, contribuir.
  • Dentro de cada seção a ordem é sempre a mesma: uma introdução logo abaixo do título, e depois entender → praticar → resolver → consultar → recomendações. As faixas dizem o que você está prestes a fazer; o selo colorido diz o tipo do documento. São eixos independentes.
  • Faixa marcada como vazia é lacuna real: aquela seção ainda não tem nenhum documento daquele papel.
  • O selo indica o tipo pelo Diátaxis — verde = tutorial (aprender fazendo), azul = guia (resolver um problema), roxo = referência (consultar), marrom = explicação (entender o porquê). Clique num selo do topo para destacar só aquele tipo.
  • Selos tracejados marcam o que precisa de decisão: gap (não existe), lacuna (tipo a confirmar), dup (a fundir), rascunho (a validar).
  • O quadrado à esquerda de cada box marca como lido — fica salvo no navegador.
  • O box Instalação tem também um roadmap próprio: ver.

Como usar

  • Linhas cinza (arestas) ligam cada nó ao seu pai na trilha — mesmo princípio visual do roadmap.sh: nó principal (roxo) no centro, sub-nós conectados por baixo.
  • Clique em qualquer nó pra marcar como concluído — fica salvo no navegador, sobrevive a reload.
  • Nós verdes ("→") são links de saída — apontam pra outra seção da documentação.
  • Redimensione a janela: as arestas recalculam a posição automaticamente.

## Escolha por intenção

| Quero mostrar… | Gráfico | Observações |
| --- | --- | --- |
| Evolução ao longo do tempo | Time-series line | *a escrever* |
| Comparação entre categorias | Bar chart | *a escrever* |
| Composição de um total | Stacked bar | *a escrever* |
| Um número único de destaque | Big Number | *a escrever* |
| Número com tendência | Big Number with Trendline | *a escrever* |
| Distribuição | Histogram / Box plot | *a escrever* |
| Relação entre duas medidas | Scatter | *a escrever* |
| Detalhe linha a linha | Table | *a escrever* |
| Recorte geográfico | *a definir* | *depende do que está habilitado* |

# Onde pedir ajuda

Referência de canais para pedir ajuda ou reportar dúvidas no GovHub.

## Canais

| Situação | Canal |
| --- | --- |
| Dúvida, sugestão ou contribuição sobre um repositório específico | Issues do próprio repositório. |
| Problema técnico em PR aberto | Comentário no PR, marcando o contexto da dúvida. |
| Dúvida geral sobre o projeto | `lablivreunb@gmail.com`. |
| Vulnerabilidade, credencial exposta ou dado sensível | Canal privado com a equipe responsável; não abra issue pública. |

## Informações úteis ao pedir ajuda

| Informação | Finalidade |
| --- | --- |
| Repositório e branch | Localiza rapidamente o contexto. |
| Link da issue ou PR | Evita conversa solta sem histórico. |
| Comando executado | Permite reproduzir o problema. |
| Log ou erro relevante | Mostra o sintoma real. |
| O que você esperava | Ajuda a separar bug, dúvida e comportamento esperado. |

## Notas

Use issues para dúvidas rastreáveis sobre trabalho técnico. Para incidentes de segurança ou exposição de credenciais, use reporte privado.

# Mapa dos repositórios

Referência rápida dos repositórios da organização GovHub-br e do papel esperado de cada um.

## Repositórios principais

| Repositório | Visibilidade | Papel |
| --- | --- | --- |
| `gov-hub` | Público | Site e documentação principal do GovHub. |
| `data-application-gov-hub` | Público | Pipeline principal de dados, com Airflow, dbt, testes e automações. |
| `continuous-deployment` | Público | Configurações de deploy, infraestrutura e GitOps. |
| `openmetadata-declarative-governance` | Público | Governança declarativa para OpenMetadata, domínios, owners e classificações. |
| `govhub-roadmap` | Público | Roadmap visual e proposta de árvore documental do GovHub. |
| `.github` | Público | Configurações públicas da organização no GitHub. |

## Forks e aplicações temáticas públicas

| Repositório | Visibilidade | Papel |

## Arquivados

| Repositório | Estado | Observação |
| --- | --- | --- |
| `gov-hubio` | Arquivado | Repositório legado; consulte os repositórios ativos antes de usar. |

## Notas

Use o repositório mais específico para abrir issue ou PR. Mudanças genéricas de contribuição, documentação ou padrões compartilhados devem ir para o repositório central correspondente, não para um fork temático.

Repositórios privados não são listados aqui. Pessoas com acesso à organização devem consultar o GitHub da GovHub-br quando precisarem encontrar projetos internos.
